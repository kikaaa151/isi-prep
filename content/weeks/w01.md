## Čo si zapamätať

- `np.arange(15).reshape(3, 5)`; `a.shape`, `a.size`, `a.sum()`, `a.sum(1)` (riadky), `a.sum(0)` (stĺpce).
- `datasets.load_digits()` / `datasets.load_iris()` → `.data` (X), `.target` (y), `.images` (len číslice).
- `plt.figure(1, figsize=(3, 3))`, `plt.imshow(obrazok, cmap=plt.cm.gray_r)`, `plt.show()`;
  `fig, axes = plt.subplots(2, 5)` a `axes.ravel()`.
- Vzorka = riadok, príznak = stĺpec, cieľová premenná = `y`; učenie s učiteľom = klasifikácia a regresia.
- Vzor každého modelu:

```python
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.25, random_state=33)
clf = LogisticRegression()
clf.fit(X_train, y_train)
y_test_predicted = clf.predict(X_test)
print(metrics.accuracy_score(y_test, y_test_predicted))
```

- `predict` potrebuje 2D vstup: `np.array([12]).reshape(-1, 1)` (jeden príznak) alebo
  `np.array([5.3, 4.1]).reshape(1, -1)` (jedna vzorka).
- Lineárna regresia: y = A + B·x, `model.intercept_` = A, `model.coef_` = B; 12-palcová pizza → 13.68 $.
- `LogisticRegression` je klasifikátor, aj keď má v názve regresiu.
- V notebooku stav závisí od poradia spúšťania buniek – pri pochybnostiach *Restart & Run All*.
